# Third-party software and fonts

All runtime code and font files are bundled locally by `npm run build`. No CDN or
font service is used by the application.

The `package-lock.json` pins the full dependency tree. OpenDyslexic WOFF2
files are committed under `public/fonts/`; Atkinson and Lexend are copied into
the static build from their local npm packages. The font notices must remain
with redistributed builds.

The WordNet subset is generated by `scripts/build-wordnet.py` from the
official [WordNet 3.0 database archive](https://wordnetcode.princeton.edu/3.0/)
and committed as a separate lazy-loaded JavaScript asset. No dictionary query
is sent to a service. The subset does not include pronunciation data.

The PP-DocLayout-S ONNX weights are 4,917,852 bytes. The exporter's model card
states that the Apache-2.0 licence is inherited from Paddle's checkpoint and
documents the 23-class I/O contract. Runtime files under `public/ort/` are
unmodified copies from `onnxruntime-web` 1.30.0. The WASM CPU path is the
supported iPadOS/iPhone fallback; WebGPU is attempted only where supported.
These application assets are fetched from Reader's own origin. Neither PDF
pages nor extracted text are sent with those requests.
